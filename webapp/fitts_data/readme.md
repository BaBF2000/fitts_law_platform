# Fitts Data Framework

## Overview

The Fitts Data Framework provides a high-level Python interface for accessing, analysing and validating experimental data generated by the Fitts Display Lab application.

The framework abstracts the underlying SQLite database and exposes convenient scientific functions for:

* Participant and session access
* Trial retrieval
* Fitts' Law metrics
* Throughput computation
* Regression analysis
* Data grouping
* Statistical summaries
* Diagnostic reports
* Scientific plotting

The framework is intended for post-processing and analysis of experimental data collected during Fitts' Law studies.

## Basic Usage

```python
from fitts_data import FittsDataClient

fd = FittsDataClient()
```

### List Participants

```python
participants = fd.participants()
print(participants)
```

### List Sessions

```python
sessions = fd.sessions(
    participant="P01"
)

print(sessions)
```

### Load Trial Metrics

Movement Time:

```python
mt = fd.get_MT(
    participant="P01",
    session="S1"
)
```

Amplitude:

```python
a = fd.get_A(
    participant="P01",
    session="S1"
)
```

Target Width:

```python
w = fd.get_W(
    participant="P01",
    session="S1"
)
```

Index of Difficulty:

```python
id_values = fd.get_ID(
    participant="P01",
    session="S1"
)
```

Throughput:

```python
tp = fd.get_throughput(
    participant="P01",
    session="S1"
)
```

## Session Summary

```python
summary = fd.session_summary(
    participant="P01",
    session="S1"
)

print(summary)
```

Example:

```text
SessionSummary(
    participant='P01',
    session='S1',
    trial_count=30,
    mean_mt_ms=686.36,
    mean_id_effective=2.33,
    total_errors=5,
    mean_throughput=3.34
)
```

---

## Participant Summary

```python
participant = fd.participant_summary(
    "P01"
)
```

This function returns all session summaries belonging to one participant.

No global average is computed across sessions because experimental conditions may differ between sessions.

```text
LinearRegressionResult(
```

````
## Grouping

Group rows by ID:

```python
groups = fd.group_by_ID(
    participant="P01",
    session="S1"
)
````

Calculate MT statistics per group:

```python
stats = fd.describe_MT_by_group(groups)

for key, summary in stats.items():
    print(key, summary.mean)
```

## Diagnostics

The framework can generate diagnostic reports describing:

* available data
* missing data
* computed values
* calibration status
* regression quality

Example:

```python
print(
    fd.session_report(
        participant="P01",
        session="S1"
    )
)
```

The report highlights:

* calibration availability
* missing IDs
* computed IDs
* available pixel values
* available millimeter values
* regression statistics

---

## Calibration Support

The framework supports both:

* pixel-based analysis
* millimeter-based analysis

When millimeter values are unavailable, conversions can be performed using the stored session calibration factor:

```text
mm_per_px
```

Diagnostic reports indicate whether calibration information is available.

## Plotting

```python
    participant="P01",

)
```

Movement time distribution:

```python
fd.plot_mt_distribution(

    session="S1"
)
```

```python
    participant="P01",
    session="S1"
)

fd.plot_boxplot_by_group(
    groups,

)
```
